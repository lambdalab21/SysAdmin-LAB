# TLCL Chapter 29 — Four-Day Guide

Chapter 29 should be split into four days.

| Day | File | Read before exercises | Main gain |
|---|---|---|---|
| Day 1 | `01_day1_looping_and_while.md` | Start of Chapter 29 through `while` | Understand what a loop condition controls |
| Day 2 | `02_day2_break_continue_select_and_menu_loops.md` | `break and continue`; read `select` if included in your edition | Control a running loop without guessing |
| Day 3 | `03_day3_until_and_condition_design.md` | `until` | Understand loop conditions from the opposite direction |
| Day 4 | `04_day4_reading_files_with_loops_final_lab.md` | `Reading Files with Loops` and `Summing Up` | Process input safely one line at a time |

Core habit:

```text
condition in English
→ initial value
→ body action
→ what changes
→ stop case
→ failure case
→ test normal and abnormal input
```

What Chapter 29 adds to previous chapters:

```text
Ch 27: if chooses once.
Ch 28: read receives input.
Ch 29: while/until repeat until a condition changes.
```

Move on only when he can explain:

```text
Why did the loop start?
Why did it continue?
Why did it stop?
What could make it loop forever?
```
